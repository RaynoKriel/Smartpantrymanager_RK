# Smartpantrymanager_RK
Mobile development assignement for a smart pantry application on andriod
A Java Android application that helps users reduce food waste by tracking pantry ingredients and suggesting recipes that can be prepared using currently available ingredients.

## Technologies

- Java
- Android Studio
- Android SDK
- SQLite (planned)
- RecyclerView (planned)
